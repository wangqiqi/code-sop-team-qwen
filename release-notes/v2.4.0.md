# 代码工程 SOP 专家团 v2.4.0 · QwenWork 版

13 位角色、9 个能力技能、四道硬闸门。装完直接在对话里 `/sop-team` 开工。

## 直接下载安装（3 步）

1. 下载下方 Assets 里的 **`code-sop-team-2.4.0.zip`**
2. 千问办公 → 左侧 **扩展 → 专家套件 → 右上「+ 添加」→ 上传套件**
3. 选中 ZIP → **安装**；新任务输入 `/`，选 `sop-team` 即可

> 千问办公的公开市场目前没有自助上架入口（企业后台只开放「企业市场 / 专属市场」），所以用 GitHub Release 作为分发渠道。这个 ZIP 与将来提交 ISV 审核的包完全一致，不用重打。

## 这个版本包含

- **9 个技能**：`sop-team`（主理人编排）、`sop-gate`（四道闸执行器）、`product-spec`、`architecture-design`、`ux-design`、`stack-conventions`、`quality-checklists`、`delivery-contracts`、`release-ops`
- **12 份角色手册**：常驻 4 人（齐活林 / 许清楚 / 严过关 / 毕达成）+ 按需 8 人，`task` 不可用时单会话代行并显式标注
- **四道硬闸 CLI** `bin/sop_gate.py`：`gate-check` 规划闸 · `task-verify` 验收闸 · `verify` 出口闸 · `followup` 补丁循环闸；fail-closed、原子锁、超时杀进程树
- **43 个回归用例** `tests/test_sop_gate.py`（零依赖）
- **素材**：14 张角色头像 + 512×512 `icon.png`（可上传到企业市场后台当图标）
- **第 0 步环境自检**：`skills/sop-team/scripts/preflight.ps1` / `preflight.sh`

| 客户端 | 千问办公（桌面端或网页端） |

## 已知边界

- 公开市场无自助入口；本 Release 即当前的分发与提交载体
- 角色以手册承载（非独立子智能体），`task` 不可用时进单会话代行模式并显式标注，不冒充独立成员结论
- 不改动你的业务仓库：状态只写 `<项目根>/.qwenwork/sop/`，`init` 会自动加进 `.gitignore`
- 任何闸门非 0 退出都不得继续编码、标完成或提交
